# ADR 0010：工作区分组与删除确认偏好

状态：已采用，始于 `0.2.0`。

## 决定

归档列表默认按原生工作区成员关系分组，未匹配的会话放入未分组；搜索、筛选和选择仍使用同一完整原生集合。行操作沿用 Models 的卡片及红色文字删除样式，使用宿主控件与语义 token。

默认保留简短的永久删除确认框，取消获得初始焦点，以一次明确的确认按钮取代额外的不可逆勾选。面板提供跨工作区的确认开关，保存在当前浏览器配置中此 Host 的独立版本化偏好，支持同源窗口同步；不写入 Host journal，也不改变生产删除资格。关闭后仅新鲜的删除按钮点击可在同一连接代次准备成功后执行，准备期间重新开启确认或重连则保留确认。missing 恢复始终重新明确确认；重载只查询已发送操作。

批次准备与运行显示有界进度和逐项日志，不占用确认对话框；用户可停止未发送项。完成或停止后保留简短统计和失败、阻止、未知项，省略成功项日志与内部资源计数。展示的收起、关闭或精简不解除持久化 pending 保护，未知结果仍暂停后续项并保留检查、同操作续办及明确继续入口。

## 影响

偏好控制额外确认的展示，不替代 Host 的固定身份、生命周期、资源与活动复核。清空范围和串行 admission window 保持 [ADR 0009](0009-fixed-purge-batches.md) 的约束。正式行为见[客户端接口](../client-interface.md)，证据见[客户端验证](../verification/client-interface.md)。
